# Arquitetura e Organização de Computadores I (AOC 1)

Repositório dedicado ao armazenamento das resoluções de exercícios práticos e trabalhos desenvolvidos na disciplina de **Arquitetura e Organização de Computadores I**.

### 💻 Conteúdo e Tópicos Abordados
- **Arquitetura MIPS:** manipulação de registradores, controle de fluxo e chamadas de sistema (syscalls).
- **Estruturas de Dados em Baixo Nível:** vetores, strings e alocação.
- **Modularização:** criação de subrotinas, convenções de passagem de argumentos/retorno e manipulação de pilha (Stack/Pilha de Execução).
- **Ferramentas:** Simulação e depuração com o software **MARS** (*MIPS Assembler and Runtime Simulator*).
