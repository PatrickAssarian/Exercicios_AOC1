# Arquitetura e Organização de Computadores I (AOC 1)

Repositório dedicado ao armazenamento das resoluções de exercícios práticos e trabalhos desenvolvidos na disciplina de **Arquitetura e Organização de Computadores I**.

### 💻 Conteúdo e Tópicos Abordados
- **Arquitetura MIPS:** manipulação de registradores, controle de fluxo e chamadas de sistema (syscalls)[cite: 2, 4].
- **Estruturas de Dados em Baixo Nível:** vetores, strings e alocação[cite: 2].
- **Modularização:** criação de subrotinas, convenções de passagem de argumentos/retorno e manipulação de pilha (Stack/Pilha de Execução)[cite: 3].
- **Ferramentas:** Simulação e depuração com o software **MARS** (*MIPS Assembler and Runtime Simulator*)[cite: 3, 4].
